Folentra Privacy Policy

Effective date: July 5, 2026
Last updated: October 20, 2026

Contact: support.folentra@gmail.com

Folentra is a personal-finance app for recording transactions, budgets, categories, tags, and local summaries. This policy describes Android package com.mojtaba.folentra.

Information stored locally

Transactions, amounts, currencies, dates, merchants, notes, budgets, categories, tags, and settings are stored in app-private storage. The Room ledger is protected by Android's app sandbox but is not encrypted by Folentra. Sensitive preferences such as App Lock state use encrypted Android shared preferences.

Financial data handling

The current app has no bank connection, server-backed account, cloud sync, import flow, advertising feature, or remote AI request path. Insights, search ranking, and autofill use on-device contracts or deterministic local fallback. App Lock limits casual UI access but does not encrypt ledger records.

Analytics and diagnostics

Firebase Analytics is included as a dependency. Release product-event behavior is no-op and feature code is not currently wired to send ledger events to Firebase. Google/Firebase SDK behavior may process technical app or device metadata. Folentra does not intentionally place exact amounts, balances, merchants, notes, search text, credentials, tokens, or raw ledger identifiers in analytics or logs.

Firebase configuration is injected only by protected release CI and is not stored in the source repository. Crashlytics is enabled only for configured release builds; debug and benchmark automatic collection remains disabled. Crash reports can include sanitized technical metadata and stack frames, but sensitive financial content must not be intentionally attached. Firebase App Distribution provides signed, minified release APKs only to authorized internal testers.

Permissions and third parties

AndroidX Biometric supports App Lock, WorkManager supports background work, Room stores local data, and AndroidX Security Crypto protects sensitive preferences. Firebase/Google dependencies can contribute internet, network-state, install-referrer, attribution, and advertising-ID permissions. The current release does not request contacts, camera, location, photos, calendar, SMS, phone, or microphone access.

Backup and device transfer

Folentra uses explicit deny-by-default Android rules. The ledger database and SQLite sidecars, encrypted preferences, app-private files, shared preferences, external files, device-protected storage, caches, logs, temporary/debug files, and generated reports are excluded from automatic cloud backup and device transfer. The backup-ready profile is a local foundation only; it does not upload, sync, or restore ledger data.

Sharing, retention, and deletion

Folentra does not sell personal data or send ledger records to a Folentra server. Records in app-private storage remain until deleted, app storage is cleared, or the app is uninstalled. Exported CSV files are separate copies and remain at their selected destinations until separately deleted. There is no server deletion portal because no server-side account or ledger exists. Firebase/Google retention, when applicable, follows the configured service policies.

Security and children's privacy

No app can guarantee complete security. Folentra does not currently protect against compromised devices, screenshots, or screen recording. It is a personal-finance utility and is not designed for children.

CSV export

You can export transactions for a date range you select from Settings. Each CSV contains transaction dates, transaction types, amounts, and currencies. Merchant names and notes are excluded by default; you can choose to include each of them before saving. Transaction IDs, categories, tags, and account metadata are not included in the current CSV format.

Folentra generates the file on your device and lets you select its destination through Android's system document picker, such as the Downloads folder. The export feature does not send the file to a Folentra server, keep a separate export cache, or log the exported contents. It does not require broad access to your device's files.

CSV files contain financial information and are not encrypted by Folentra. App Lock does not protect files saved outside the app. If you select a cloud storage provider, that provider may upload and store the file under its own privacy policy and settings. If you later open or share it with another app or person, that recipient can access the information you included.

Exported files are separate copies of your records. Editing or deleting a transaction, clearing Folentra's storage, or uninstalling Folentra does not remove copies saved in Downloads or another external destination. Delete those files yourself using your file manager or storage provider, and manage any shared copies with their recipients. A failed save may leave an incomplete file at the selected destination; you can delete it there.

Folentra's automatic backup exclusions apply to app-managed data, not to CSV files you save elsewhere. Your chosen storage provider controls any backup, retention, or deletion of those exported files. CSV export does not provide automatic sync or a backup-and-restore service.

For privacy questions about Folentra or its CSV export feature, contact support.folentra@gmail.com.

Changes

This policy is updated when analytics, crash reporting, accounts, cloud sync, backup, import/export, AI providers, permissions, or third-party services change. The last-updated date at the top identifies the latest revision.
